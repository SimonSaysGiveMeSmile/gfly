# Third-party art under web/public/assets

Nothing in this directory was drawn or generated for this project; every file is
a found asset from the sources below. Fetched by `tools/fetch_assets.py`
(Poly Haven) and `tools/fetch_game_assets.py` (everything else). Per-file
Commons credits are also in `commons_credits.json`.
